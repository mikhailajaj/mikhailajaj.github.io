Tarneeb Online – Real-Time Multiplayer Card Game

Mobile card game with strategic AI, smooth animations, and authentic Middle Eastern gameplay

3 months
Team of 1
Full-Stack & Game Developer

Project Overview

A fully-featured mobile implementation of Tarneeb, a popular Middle Eastern trick-taking card game, built with React Native and Expo. Features single-player mode with three strategic AI opponents, beautiful card animations, comprehensive game logic with bidding and trump selection, and an intuitive touch interface that preserves the cultural authenticity of the traditional game.

View Live DemoView Source Code

The Challenge

Designing a deterministic, cheat-proof game engine with sophisticated AI opponents was critical. The AI needed to make intelligent bidding decisions based on hand strength, follow complex suit rules, play strategically with trump cards, and coordinate with partners—all while maintaining smooth 60 FPS animations and responsive touch interactions on mobile devices.

The Solution

Implemented a finite-state machine game engine with React Context and Reducer pattern for deterministic state management. Developed modular AI system with strategic bidding algorithms that evaluate hand strength and intelligent card play logic that follows suit rules, manages trump cards wisely, and coordinates with partner AI. Used React Native Animated API with native driver for smooth card animations, and comprehensive test coverage to ensure game rule compliance.

Preserves cultural heritage by digitizing a beloved Middle Eastern card game, making it accessible to players worldwide while demonstrating advanced mobile game development, AI decision-making, and cross-platform engineering capabilities.
